# SomaMind-AI-ML
Two independent AI/ML applications for wellness context recognition and personalized habit analysis.
## Core Concept and Motivation
SomaMind AI aims to encourage people to pause before automatically reaching for painkillers or muscle relaxants for minor everyday discomfort. It promotes awareness of simple self-care alternatives, such as gentle exercise, stretching, walking, hydration, and relaxation.
Using AI and Machine Learning, the application analyses how users describe their current situation and suggests suitable wellness activities.
